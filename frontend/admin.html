Admin sign in

Enter the demo admin key (default: demo-admin-change-me). Set MNH_ADMIN_KEY to change it.

Upload an examination

Use the sample exam or choose a JSON file, optionally with a PDF or image question paper. The active exam is what students receive.

Tap the button to fill a ready exam, or choose your own .json file.

Expected JSON format 
{
  "title": "Antenatal Care Assessment",
  "duration_minutes": 45,
  "questions": [
    { "type": "mcq", "text": "How often is antenatal care recommended?", "marks": 5,
      "options": ["Once", "At least four visits", "Only if unwell", "Never"],
      "answer": 1 },
    { "type": "text", "text": "Describe two danger signs in pregnancy.", "marks": 10 }
  ]
}

Question ids are assigned automatically. For MCQs, answer can be a 0-based index (1 = option B), a letter ("B") or the exact option text. It is hidden from students and used for automatic marking.
